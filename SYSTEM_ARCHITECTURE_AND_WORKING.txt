1. OVERVIEW
================================================================================

The EEG-Kinova system is a Brain-Computer Interface (BCI) that allows users to
control a Kinova robotic arm using EEG (electroencephalogram) signals. The
system supports two modes of operation:

  - Option 5: EEG-only control (arm moves purely based on EEG predictions)
  - Option 6: EEG + OpenCV hybrid (arm speed depends on match between EEG
    prediction and visual tracking)

The complete pipeline consists of:
  1. Data Collection (EEG signals from Unicorn device)
  2. Preprocessing (prepare data for each model type)
  3. Model Training (EEGNet, FBMSNet, CTNet)
  4. Real-time Control (EEG prediction → Kinova arm movement)

--------------------------------------------------------------------------------
HARDWARE SETUP REFERENCE
--------------------------------------------------------------------------------

The controllers (kinova_eeg_controller.py, kinova_eeg_opencv_controller.py) and
real_time_eeg_predictor.py use hardware_config.py for their settings. Edit
hardware_config.py to change robot IP, angles, speed limits, EEG sample rate,
camera settings, etc.

The reference files keep their original configuration:
  - OpenCV/track_ball_kinova_test_fixed.py  → Kinova arm (standalone)
  - dataCollection.py                       → EEG headset (standalone)

Keep hardware_config.py values in sync with these references for consistency.

--------------------------------------------------------------------------------
3.1 DATA COLLECTION (dataCollection.py) — EEG HEADSET SETUP REFERENCE
--------------------------------------------------------------------------------

Purpose:
  Collects EEG data from the Unicorn Hybrid Black device while the user performs
  motor imagery tasks (e.g., thinking about different colors/directions).

  *** This file is the REFERENCE for EEG headset setup. All EEG streaming logic
      (connection, sampling, buffer size) in real-time controllers follows this.

Hardware (from dataCollection.py):
  - Unicorn Hybrid Black: 8 EEG channels (or 17 for full device)
  - Sampling rate: 250 Hz
  - Connection: UnicornPy.GetAvailableDevices() → Unicorn(device) → StartAcquisition()
  - Display: PyQt5 GUI showing baseline, instruction, and stimulus phases

Data Flow:
  1. User starts experiment → stabilization phase (e.g., 20 seconds)
  2. For each trial: Baseline → Instruction (think about color) → Stimulus
  3. UnicornRecorder thread reads samples via GetData(), writes to CSV
  4. CSV format: trial_index, class_label, phase, timestamp, Ch1...Ch8 (or Ch17)

Output:
  - EEG_bar_trials_{N}_classes_{K}_{timestamp}.csv
  - Saved in project root or specified folder

Key Parameters:
  - num_classes: 2 or 3 (or 5)
  - trials_per_class: e.g., 20 or 50
  - baseline_ms, instruction_display_ms, stim_ms: phase durations

--------------------------------------------------------------------------------
3.2 PREPROCESSING (preprocessing_3_class_*.ipynb)
--------------------------------------------------------------------------------

Purpose:
  Convert raw CSV EEG data into model-ready .npy arrays with proper filtering,
  trial extraction, and normalization.

Three Notebooks (one per model):

  A) preprocessing_3_class_CTNet.ipynb
     - Input: CSV from data/2_class/ or data/3_class/
     - Bandpass filter: Butterworth, zero-phase (filtfilt)
       * FILTER_TYPE='notebook': 4-40 Hz, order=5
       * FILTER_TYPE='data_curation': 8-30 Hz, order=5
     - Trial extraction: trial_index-based or automatic phase detection
     - Output shape: (N, 8, 250) - N samples, 8 channels, 250 timepoints (1 sec)
     - Output files: X_train_ctnet.npy, y_train_ctnet.npy, X_test_ctnet.npy,
       y_test_ctnet.npy

  B) preprocessing_3_class_FBMSNet.ipynb
     - Input: Same CSV
     - Bandpass filter: Two-stage
       * Stage 1: Broad bandpass 4-40 Hz (or 8-30 Hz via FILTER_TYPE), order=4
       * Stage 2: 9-band filterbank (delta, theta, alpha, beta, etc.) - each band
         uses bandpass_filter_band(lowcut, highcut) with butter + filtfilt
     - Baseline normalization (baseline also bandpass-filtered)
     - Output shape: (N, 9, 8, 248) - N samples, 9 bands, 8 channels, 248 timepoints
     - Output files: X_train_fbmsnet.npy, y_train_fbmsnet.npy, etc.

  C) preprocessing_3_class_EEGNet.ipynb
     - Input: Same CSV
     - Bandpass filter: Butterworth, zero-phase (filtfilt)
       * FILTER_TYPE='notebook': 4-40 Hz, order=5
       * FILTER_TYPE='data_curation': 8-30 Hz, order=5
     - Epoch creation, baseline normalization (baseline also bandpass-filtered)
     - Output shape: (N, 1, 8, T) - N samples, 1 (EEGNet expects 4D), 8 channels
     - Output files: X_train_eegnet.npy, y_train_eegnet.npy, etc.

GUI Integration:
  - NotebookWorker patches notebook JSON to use data/N_class/ path
  - Runs nbconvert --execute on each notebook sequentially
  - Copies CSV files from user-selected folder to data/2_class/ or data/3_class/

3.3 MODEL ARCHITECTURES
--------------------------------------------------------------------------------

A) EEGNet (EEGNet_new_model.py, EEGNet_new_training.py)
   - Input: (batch, 1, 8, 250) or (batch, 8, 250)
   - Output: (batch, num_classes)

   Architecture (Improved EEGNet):
     Block 1 - Temporal Conv:
       Conv2d(1, F1=16, kernel=(1, 125)), BatchNorm
       → Learns temporal/frequency features (0.5s kernel at 250 Hz)
     Block 2 - Depthwise Spatial Conv:
       Conv2d(F1, F1*D=32, kernel=(8, 1), groups=F1), BatchNorm, ELU
       AvgPool2d(1, 4) → reduces time by 4x
       SpatialDropout2d or Dropout
     Block 3 - Separable Conv:
       Conv2d(32, F2=16, kernel=(1, 16)), BatchNorm, ELU
       AvgPool2d(1, 8) → reduces time by 8x
       Dropout
     Classifier: Linear(flattened_size, num_classes)

   Key params: F1=16, D=2, F2=16, k_temporal=125, dropout_rate=0.5
   Optional windowing in training for data augmentation
   Saves to: outputs/eegnet_new_best.pth

--------------------------------------------------------------------------------

B) FBMSNet (FBMSNet/codes/centralRepo/networks.py)
   - Input: (batch, 9, 8, 248) - 9 frequency bands, 8 channels, 248 timepoints
   - Output: (logits, features) - LastBlock uses LogSoftmax

   Architecture (FBMSNet with MixedConv2d):
     MixedConv2d (temporal multi-scale):
       9 in → num_Feat=36 out, kernel sizes [(1,15),(1,31),(1,63),(1,125)]
       → 4 parallel convs with different temporal receptive fields
       BatchNorm
     SCB (Spatial Convolution Block):
       Conv2dWithConstraint(36, 36*dilatability=288, (8,1), groups=36)
       BatchNorm, swish
     Reshape: [*, *, 4, T/4] (strideFactor=4)
     Temporal aggregator: LogVarLayer(dim=3) - log variance over time
     Flatten
     LastBlock: LinearWithConstraint → Linear → LogSoftmax

   Key params: nChan=8, nTime=248, num_Feat=36, dilatability=8, dropoutP=0.6
   Expects data in FBMSNet/data/
   Saves to: FBMSNet/fbmsnet_best_model.pth

--------------------------------------------------------------------------------

C) CTNet (ctnet_model.py, ctnet_training.py)
   - Input: (batch, 8, 250)
   - Output: (logits, features) - training returns tuple

   Full CTNet (optional):
     CTNetConvModule: Temporal Conv → Depthwise → Spatial Conv
       F1=8, D=2, F2=16, Kc1≈63, P1=8, P2=2 → (B, Tc≈15, 16)
     PositionalEncoding (optional)
     TransformerEncoder: 6 layers, 2 heads, d_model=16
     Fusion: seq_cnn + seq_transformer
     Pooling: avg + 0.3*max
     Classifier: Linear(16, n_classes)

   CTNetLite (used in training):
     CTNetConvModule: F1=4, D=1, F2=8, Kc2=8, P1=5, P2=2
     TransformerEncoder: 2 layers, 2 heads, d_model=8
     Fusion + pooling (same as full)
     Classifier: Linear(8, n_classes)

   Key params (Lite): F1=4, D=1, F2=8, dropout_conv=0.5
   Saves to: ctnet_best_model.pth

--------------------------------------------------------------------------------
3.4 MODEL TRAINING CONFIGURATION
--------------------------------------------------------------------------------

A) EEGNet Training (EEGNet_new_training.py)
   - Loss: CrossEntropyLoss with class weights (for imbalance)
   - Optimizer: Adam, lr=1e-4, weight_decay=1e-4
   - Scheduler: ReduceLROnPlateau (mode='min', factor=0.1, patience=10, min_lr=1e-6)
   - Early stopping: patience=100, monitor val_loss
   - Epochs: 300 (max)
   - Batch size: 16
   - Train/val split: 90/10
   - Optional: Windowing (window_size=250, step_size=75) for data augmentation
   - Saves: best model (val_loss), last model, log CSV, label map JSON

B) FBMSNet Training (FBMSNet/train_custom_fbmsnet_updated.py)
   - Loss: CrossEntropyLoss
   - Optimizer: Adam, lr=3e-3 (fixed, no scheduler)
   - Epochs: 250
   - Batch size: 16
   - Train/val split: 90/10 random_split
   - Saves best model by validation accuracy
   - Outputs: training curves PNG, confusion matrix PNG, checkpoint .pth

C) CTNet Training (ctnet_training.py)
   - Loss: FocalLoss (alpha=0.25, gamma=1.0) with class weights
     (addresses class imbalance and hard examples)
   - Optimizer: AdamW, weight_decay=3e-4
   - Learning rate search: tests [1e-4, 3e-4, 1e-3, 3e-3, 1e-2]
   - Scheduler: ReduceLROnPlateau (mode='max', factor=0.5, patience=30, min_lr=1e-6)
   - Early stopping: patience=100, monitor validation accuracy
   - Epochs: 300 per learning rate (LR search runs 5 LRs)
   - Batch size: 16
   - Train/val split: 90/10
   - Gradient clipping: max_norm=1.0
   - Saves best model across all LRs (highest val_acc)

3.5 REAL-TIME EEG PREDICTOR (real_time_eeg_predictor.py)
--------------------------------------------------------------------------------

Purpose:
  Load a trained model and run inference on streaming EEG data.

Components:
  - Buffer: Accumulates 250 samples (1 second at 250 Hz)
  - Preprocessing: Bandpass filter (4-40 Hz), z-score normalization
  - Model inference: Forward pass, softmax for class probabilities

Data Flow:
  1. add_samples(samples) - append (N, 8) samples to buffer
  2. predict() - when buffer has 250 samples:
     - Apply bandpass filter
     - Z-score normalize
     - Reshape for model (depends on EEGNet/CTNet/FBMSNet)
     - Run model.forward()
     - Return (predicted_class, probability_array)

Model-Specific Input Shapes:
  - EEGNet: (1, 1, 8, 250)
  - CTNet: (1, 8, 250)
  - FBMSNet: (1, 9, 8, 248) - simplified multiband replication for real-time

--------------------------------------------------------------------------------
3.7 OPTION 5: EEG-ONLY CONTROLLER (kinova_eeg_controller.py)
--------------------------------------------------------------------------------

Purpose:
  Control the Kinova arm purely from EEG predictions. No camera or OpenCV.

Flow:
  1. Connect to Kinova → move to ANGLES_INIT
  2. Start EEG stream (Unicorn or mock)
  3. Every 1 second: predict class from EEG buffer
  4. Map class to velocity:
     - Class 0: vx = -V_MAX (one direction)
     - Class 1: vx = +V_MAX (other direction)
     - Class 2 (3-class): vx = 0 (stop)
  5. Clamp: respect workspace limits (X_MIN, X_MAX)
  6. send_vx(base, vx)

--------------------------------------------------------------------------------
3.8 OPTION 6: EEG + OPENCV CONTROLLER (kinova_eeg_opencv_controller.py)
--------------------------------------------------------------------------------

Purpose:
  Control the arm using both EEG and visual tracking. Match = fast, mismatch =
  slow.

Flow:
  1. Camera calibration: user clicks 4 corners (TL, TR, BR, BL)
  2. Connect Kinova → move to ANGLES_INIT
  3. Start EEG stream
  4. Main loop (60 Hz):
     a) Capture frame, warp to top-down view
     b) Detect blue ball (HSV), red bar (HSV)
     c) Kalman filter for ball position and velocity
     d) Compute vx_cmd from vision: where bar should move to intercept ball
     e) OpenCV direction: vx < -0.02 → 0, vx > 0.02 → 1, else → 2
     f) EEG prediction (every 0.5 s)
     g) Match/mismatch:
        - If EEG_pred == OpenCV_dir: vx_cmd *= 1.0 (fast)
        - If EEG_pred != OpenCV_dir: vx_cmd *= 0.25 (slow)
     h) send_vx(base, vx_cmd)

Logic:
  When the user's EEG prediction agrees with where the ball is going (OpenCV),
  the arm moves at full speed. When they disagree, the arm moves slowly to
  reduce errors or allow correction.

7. TROUBLESHOOTING
================================================================================

- No model found: Train first; ensure .pth files exist in expected paths
- Robot connection failed: Check ROBOT_IP, network, Kortex API
- Unicorn not found: Install UnicornPy, connect device
- Preprocessing fails: Ensure CSVs in data/N_class/, check notebook paths
- FBMSNet training: Copy .npy files to FBMSNet/data/ (GUI does this)
